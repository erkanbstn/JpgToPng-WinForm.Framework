# JPG'den PNG'ye

Seçilen JPG dosyasını PNG olarak kaydeden masaüstü uygulaması.

## Ne var

Dönüştürme tek bir Windows Forms ekranındadır.

## Çalıştırma

Çözümü Visual Studio ile açıp başlangıç projesini çalıştırın. Veritabanı kullanan projelerde bağlantı dizesini kendi ortamınıza göre güncelleyin.

## Yığın

.NET Framework ve Windows Forms.
